# 怦然 PulseCast

**主播心率直播伴侣** — 开源、本地优先的心率直播叠加工具。

把智能手表 / 心率胸带通过 **本地 BLE 直连**，实时呈现在 OBS 直播画面中。零云端依赖，延迟 < 100ms。

## 中文

### 功能特性

- **本地 BLE 直连**：标准心率服务（0x180D / 0x2A37），支持 Amazfit、华为、小米、胸带等 BLE 心率设备
- **OBS 浏览器源**：三套叠层样式（心跳药丸 / ECG 波形 / 极简大数字），透明背景即插即用
- **OBS 原生插件**：C 语言实现的心率源 + 心跳抖动滤镜 + 心跳发光滤镜，性能更优
- **VRChat OSC**：心率实时推送到 VRChat avatar 参数 + ChatBox
- **阈值动作**：心率越界自动触发 OBS 场景切换 / 边缘告警脉冲
- **移动端遥控**：手机浏览器同局域网直连，远程切换场景 / 调阈值 / 高光闪烁
- **设置持久化**：重启后保留设备配对、阈值、OBS 配置
- **安全加固**：WS token 认证 + HTTP Origin 校验，同机其他进程无法控制

### 快速开始

#### 方式一：下载 Release（推荐）

从 [GitHub Releases](../../releases) 下载对应平台安装包：
- macOS：`.dmg`
- Windows：`.exe` 安装程序

安装后启动，按 FTUE 三步引导操作：连接设备 → 预览心率 → 复制 OBS 源地址。

#### 方式二：从源码运行

```bash
# 克隆仓库
git clone https://github.com/user/pulsecast.git && cd pulsecast

# 运行 Rust 服务（模拟心率源，无需蓝牙设备）
cargo run -p pulsecast-server -- --webroot .

# 启用真实 BLE 读取
cargo run -p pulsecast-server --features ble -- --webroot . --real

# 浏览器打开 http://localhost:4567/ 查看 FTUE
# OBS 浏览器源填 http://localhost:4567/obs?style=pill
```

#### 方式三：Tauri 桌面应用

```bash
npm install
npm run tauri dev     # 开发模式
npm run tauri build   # 生产构建
```

### OBS 配置

添加「浏览器源」→ URL 填：

```
http://localhost:4567/obs?style=pill&scale=1
```

可选参数：
| 参数 | 说明 | 示例 |
|------|------|------|
| `style` | 叠层样式 | `pill` / `ecg` / `number` |
| `scale` | 缩放倍率 | `0.4` ~ `2.0` |
| `ws` | 自定义 WS 地址 | `ws://192.168.1.10:4567/ws` |
| `token` | 认证 token（Tauri 桌面端生成） | `a1b2c3d4e5f60718` |
| `demo` | 强制演示模式 | `1` |

> **Token 说明**：通过 Tauri 桌面端启动时，服务端会生成认证 token。OBS 浏览器源需在 URL 中附加 `&token=xxx` 才能连接。独立运行 `cargo run` 时默认无 token，可省略。

## English

### Features

- **Local BLE direct connection**: Standard Heart Rate Profile (0x180D / 0x2A37). Works with Amazfit, Huawei, Xiaomi, chest straps, and any BLE HR device.
- **OBS Browser Source**: Three overlay styles (Heart Pill / ECG Waveform / Minimal Number). Transparent background, plug-and-play.
- **OBS Native Plugin**: C-based heart rate source + heartbeat shake filter + glow filter for better performance.
- **VRChat OSC**: Real-time heart rate pushed to VRChat avatar parameters + ChatBox.
- **Threshold Actions**: Auto-trigger OBS scene switches / edge alert pulses when HR crosses thresholds.
- **Mobile Remote**: Phone browser on same LAN for scene switching / threshold adjustment / flash highlight.
- **Persistent Settings**: Device pairing, thresholds, and OBS config survive restarts.
- **Security**: WS token auth + HTTP Origin validation. No unauthorized local process can control your stream.

### Quick Start

#### Option 1: Download Release (Recommended)

Download from [GitHub Releases](../../releases):
- macOS: `.dmg`
- Windows: `.exe` installer

Launch and follow the 3-step FTUE: Connect device → Preview HR → Copy OBS source URL.

#### Option 2: Run from Source

```bash
git clone https://github.com/user/pulsecast.git && cd pulsecast

# Run with simulated heart rate (no BLE device needed)
cargo run -p pulsecast-server -- --webroot .

# Enable real BLE
cargo run -p pulsecast-server --features ble -- --webroot . --real

# Open http://localhost:4567/ for FTUE
# OBS Browser Source URL: http://localhost:4567/obs?style=pill
```

#### Option 3: Tauri Desktop App

```bash
npm install
npm run tauri dev     # Development
npm run tauri build   # Production build
```

### OBS Setup

Add a "Browser" source → URL:

```
http://localhost:4567/obs?style=pill&scale=1
```

Parameters:
| Param | Description | Values |
|-------|-------------|--------|
| `style` | Overlay style | `pill` / `ecg` / `number` |
| `scale` | Scale factor | `0.4` ~ `2.0` |
| `ws` | Custom WS endpoint | `ws://192.168.1.10:4567/ws` |
| `token` | Auth token (generated by Tauri desktop app) | `a1b2c3d4e5f60718` |
| `demo` | Force demo mode | `1` |

> **Token note**: When launched via the Tauri desktop app, the server generates an auth token. OBS browser sources must append `&token=xxx` to the URL to connect. When running standalone via `cargo run`, no token is required by default.
